Portal de Normativas DGCyE

Portal web dinámico para centralizar la búsqueda, consulta y descarga de normativas, resoluciones, circulares y planes de estudio de la Educación Técnico Profesional de la Provincia de Buenos Aires.

Proyecto correspondiente a la Actividad 18 de la materia Proyecto de Implementación de Sitios Web Dinámicos (PWD) - EET N.º 1 “Eduardo Ader”.

Entregables de esta etapa
- docs/requerimientos_dgce.md: minuta de entrevista, requerimientos funcionales y no funcionales, y modelo de datos inicial en JavaScript.
- docs/minuta_entrevista_dgce.pdf: minuta de entrevista en formato PDF.
- docs/mockup_portal_dgce.png: boceto digital de la interfaz principal.

Tecnologías y recursos previstos
- HTML, CSS y JavaScript.
- JavaScript filter() para el filtrado de normativas.
- Fetch API para obtener datos de forma asíncrona.
- SheetJS para trabajar con planillas de cálculo, si se incorpora esa funcionalidad.
